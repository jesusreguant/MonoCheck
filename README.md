# MonoCheck

Detector mono / estéreo con picómetro, por TxuSo.

- **App para Mac** (sin DAW): elige la entrada de audio con el engranaje.
- **Plugin** VST3 (macOS y Windows) y AU (macOS).
- Se compila con GitHub Actions: pestaña **Actions** → última ejecución → **Artifacts**.
  - macOS: `MonoCheck-App-x.y.z.dmg` (app) y `MonoCheck-Plugins-x.y.z.pkg` (VST3 + AU).
  - Windows: `MonoCheck.vst3` en un zip.
